# RideSafe_women_booking_app

## Reimagining Ride-Hailing Safety Through a Proactive AI Companion

RideSafe AI is an independent Product Management case study exploring how technology can make ride-hailing safer by shifting from reactive emergency features to proactive safety assistance.

Rather than treating safety as a hidden SOS button used only during emergencies, this project imagines a product that continuously supports, reassures, and assists users throughout their journey.

The proposed solution introduces **Guardian AI**, a context-aware safety companion that helps users navigate potentially unsafe situations while keeping safety features accessible throughout the ride experience. 

---

## Project Overview

Ride-hailing platforms have transformed urban transportation, but many users—especially women travelling alone—continue to experience uncertainty during different stages of a ride.

This project explores one central question:

> **How might we redesign the ride experience so that safety becomes an active, visible part of every journey instead of a hidden emergency feature?**

The focus is not on replacing existing ride-booking platforms, but on improving trust, confidence, and accessibility through thoughtful product design.

---

## Project Objectives

- Understand safety concerns across the ride journey
- Study existing ride-hailing safety experiences
- Identify opportunities for proactive safety interventions
- Design features that reduce user anxiety during rides
- Translate insights into structured product requirements
- Build an interactive product prototype
